A dependency-free, faster drop-in for csv-reader 1.0.0. It uses indexed character-code scanning and slices each field once instead of appending one character at a time, while reproducing every broken-row error exactly.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/input MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```
